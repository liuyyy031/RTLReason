# Gold Development Set

This directory contains independently annotated development records produced by
`rtlreason promote-case --split development`.  Pending candidates and blinded
review packets do not belong here.  Prompt, dependency, and attribution changes
may use this split, but every change must be versioned.

Current independently annotated Gold records: **47**.

All available annotations pass the promotion checks. Newer evaluator
predictions belong in versioned experiment snapshots under `runs/metrics/`.
